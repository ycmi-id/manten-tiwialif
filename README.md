# Website Panitia Tiwi & Alif

Website statis responsive untuk GitHub Pages.

## Cara upload
1. Buat repository baru di GitHub.
2. Upload `index.html` dan folder `assets` (beserta `logo-ta.png`) ke root repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main`, folder `/(root)`, lalu **Save**.
6. Tunggu proses deployment, kemudian buka URL GitHub Pages yang ditampilkan.

Tidak perlu build, npm, atau framework. Cukup HTML, CSS, dan JavaScript.
