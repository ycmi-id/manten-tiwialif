# Website Panitia Tiwi & Alif

Website statis responsif untuk GitHub Pages, dengan tema biru-kuning, font Open Sans, agenda berstatus otomatis, pencarian panitia/vendor, rundown, dan checklist.

## Cara upload ke GitHub Pages
1. Ekstrak ZIP.
2. Upload `index.html`, `README.md`, dan folder `assets` ke root repository GitHub.
3. Buka **Settings → Pages**.
4. Pilih **Deploy from a branch**, branch `main`, folder `/(root)`, lalu **Save**.
5. Buka URL GitHub Pages setelah deployment selesai.

Tidak perlu build, npm, atau framework. Status agenda memakai tanggal dan jam lokal perangkat pengunjung. Acara berstatus **Selesai / Done** setelah jam akhir, **On Progress** selama rentang acara pada hari tersebut, dan **Akan Datang** sebelum dimulai.
